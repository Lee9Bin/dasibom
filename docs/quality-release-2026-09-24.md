- 지역 카드와 홈에서 종로구·중구 등 시군구 이름을 그대로 표시한다.

- 지도 경계와 서비스 지역 252개 코드 기준을 일치시켰다. 광주·전남의 일대일 변경 코드 27개를 연결했다. 통합·분할로 단순 연결할 수 없는 인천 3개 구의 방문량은 회색 ‘자료 없음’으로 표시한다.
- 오늘의 동네는 실제 방문량이 비교 지역의 하위 절반인 정책지역 후보에서 고른다. 집중률은 대상 관광지 이름을 표시하고 ‘지금 한적함’으로 단정하지 않는다.
- 데이터가 없는 숙박·체험 테마 필터는 준비 중으로 표시했다.

## 다음 우선순위

1. 전국 테마 분류: 현재 대다수 지역은 DISCOVERY로 남아 있다. 수요 지표와 실제 콘텐츠를 기준으로 분류 규칙을 정하고, 숙박·체험 필터에 충분한 지역을 연결한다.
2. 지역별 콘텐츠 검수: 자동 장소 묶음에서 다른 제목·불완전한 메타데이터로 남는 유사 사진, 빈 관광지, 추천 품질을 순차 점검한다. 사진이 적은 곳은 억지로 장수를 늘리지 않는다.
3. 취향에서 일정으로 연결: 조회 가능한 연관 관광지·반려동물·생태·웰니스 API를 실제 사용자 흐름에 필요한 순서로 연동한다. 현재는 접근 가능 여부만 확인했다.
4. 운영 준비: 각 API의 운영계정·일일 호출 한도 확인, 장애 알림과 DB 외부 백업, 실사용 부하에 맞춘 서버·요청량 점검.
5. 행정구역 기준 갱신: 인천 통합·분할을 포함해 DB·URL·지도·API 코드를 함께 이관하는 별도 설계가 필요하다. 지금은 기존 지역 주소를 유지한다.
