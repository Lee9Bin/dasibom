# OpenAPI 실시간 활용 명세

## 운영 원칙

- 브라우저는 서비스키를 받지 않고 Spring Boot 백엔드만 한국관광공사 OpenAPI를 호출한다.
- 관광사진, 관광지·음식점·숙박, 방문자, 자원 수요, 집중률 응답은 서비스 DB에 저장하거나 장기 캐싱하지 않는다.
- 각 화면 요청이 실제 OpenAPI 호출로 이어진다.
- MySQL은 공식 지역 코드, 에디터 추천 정보와 익명 좋아요 등 서비스 자체 데이터에만 사용한다.
- API 호출 로그에는 오퍼레이션, 성공 여부, 항목 수와 소요 시간만 기록한다. 서비스키와 전체 요청 URL은 기록하지 않는다.

## 기능별 OpenAPI 활용

| 서비스 기능 | 호출 오퍼레이션 | 호출 시점 | 화면 활용 |
| --- | --- | --- | --- |
| 오늘의 동네·수상작 | `PhokoAwrdService/phokoAwrdList` | 홈, 지역 상세 요청 | 수상작 원본, 촬영지, 수상 구분 |
| 방문량·숨은 점수 | `DataLabService/locgoRegnVisitrDDList` | 홈, 전국 지도 요청 | 최신 제공일 시군구 방문량의 역순위 점수 |
| 대표사진·사진 산책 | `PhotoGalleryService1/gallerySearchList1` | 지역 카드와 상세 요청 | 페이지형 갤러리, 촬영자·촬영월 |
| 17개 수요 지표 | `AreaTarResDemService/areaTarSvcDemList`, `areaCulResDemList` | 지역 상세 요청 | 관광 서비스 12개·문화자원 5개, 6개 테마 레이더 |

| 한적한 날짜 | `TatsCnctrRateService/tatsCnctrRatedList` | 지역 상세 요청 | 향후 집중률과 낮은 날짜 3개 |

## 데이터 흐름

```text
브라우저 → Next.js 동일 출처 API → Spring Boot → 한국관광공사 OpenAPI
                                      ↓
                         응답 검증 후 즉시 화면 반환
```

사진 URL은 허용된 공식 호스트인지 확인하고 `Range: bytes=0-0` 요청으로 원본이 실제 이미지인지 검증한다. `404`, HTML 응답과 타임아웃 이미지는 화면에서 제외한다.

## 지역 범위

공식 시군구 코드표의 252개 고유 지역을 검색 대상으로 제공한다. 지도 정책 분류는 행정안전부 인구감소지역 89곳·관심지역 18곳을 사용하고, 반값여행은 대한민국 구석구석 공식 페이지의 현재 참여지역 25곳을 사용한다. 전국 경계는 통계청 SGIS 기반 `vuski/admdongkor`의 2025-12-31 CC BY 4.0 데이터를 시군구로 병합해 사용한다. [가공 및 기준](../frontend/public/data/README.md)을 따른다.

오늘의 동네는 정책지역 중 관광사진 수상작이 있는 후보를 구성하고, 최신 제공 방문량의 역순위 점수가 50 이상인 후보 중 한국 날짜로 순환한다. 방문량 응답을 확인하지 못하면 사진 기준의 소개임을 알린다. 원천 API가 비어 있으면 이전 응답을 DB에서 대신 제공하지 않는다.

## 출처 표기

- 관광정보: `출처: ⓒ한국관광공사`
- 관광사진: `출처: ⓒ한국관광콘텐츠랩`

기관 CI/BI 이미지는 사용하지 않고 텍스트 출처만 표시한다.

## 2026-09-24 품질 보완

- 지역명은 시·군·구를 생략하지 않는다.
- 사진은 최근 최대 300개와 수상작 후보를 실시간 조회한 뒤 장소명·키워드·촬영지로 묶어 장소별 대표 사진을 제공한다. 이미지 내용 자체의 유사도를 모델로 판별하는 기능은 아니다. 전체 원본 사진 수와 장소별 대표 사진 수는 다르다.
- 지도는 서비스 252개 코드와 일치하는 2025-12 경계를 사용한다. 현재 행정구역과 기준이 다를 수 있음을 화면에 표시한다. 변경된 방문량 코드는 일대일 관계만 연결한다. 결측은 별도 회색으로 표시한다.
- 자원 수요는 aggregate 코드로 제공월을 찾고, 17개 세부 지표 코드를 명시해 조회한다. 병렬 호출 수와 대기 시간을 제한한다. 17개 수치는 SNS·소비·검색 수요이며 장소의 품질 평가 점수가 아니다.
- 상세 사진·관광정보·지표·방문 예측을 각각 표시해 하나의 지연이 전체 본문을 막지 않도록 한다.
